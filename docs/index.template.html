      How verification works

      VERIFIED — confirmed against the program's own site or announcement in the current check cycle. INFERRED — drawn from secondary reporting (press, guides). A lead, not a fact: re-verify before applying. GUESSED / UNKNOWN — the evidence doesn't support more, and the page says so.

      Re-checks run on a schedule. A failed fetch never silently flips a program — the status is held and a concern is written to the ledger below. Nothing here is advice.
